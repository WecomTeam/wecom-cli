# 政务增量契约（命中政务闸门时叠加）

> 本文件**只写增量与更严的项**，[content-contract.md](content-contract.md) 的全部条款照常生效；两边同一维度冲突时**以严者为准**。
>
> **何时加载**：`assets/templates/index.json` 的 `gate.trigger_zh` 命中时。命中同时意味着**候选范例套只能在 `broadside` / `long-table` 两套里取**（预览卡只出 2 张），不进全池打分。

## 1. 增量内容原则

- **中文优先**：正文、图说、图表标签、章节副标、致谢页一律中文。允许的结构性英文只有 `CONTENTS` / `PART` / `CHAPTER` / `PREFACE` / `KPI` / `SWOT` / `SMART` / `PEST` 与数字、单位符号。**禁** SECTION 标识、kicker 字样、THANK YOU、正文英文短语、图表轴英文、把中文再翻一遍的装饰英文。
- **措辞中性务实**：示例内容不写具体口号、人名、机构名。
- **美术层与内容页分离**：封面、目录、章节过渡可更强视觉；内容页一律用稳定母版。
- **零旋转纪律**：一切可见元素 0°，仅 SVG 图表内部几何线例外。
- **禁廉价符号**：印章 / 钤印 / 落款章、红绸铺满、满屏金光、整屏暗蒙版、局部矩形色块压图。

## 2. 更严的信息下限（覆盖通用表对应行）

| 类型 | 政务下限 |
| :-- | :-- |
| 封面 | 主标 + 副标 + 汇报人 / 时间 + ≥4 件装饰，整屏视觉 ≥85% |
| 章节过渡 | 编号 + 中文章节名 + **中文**副标 + 关键词点，≥30 字 |
| 单主题页 | 正文 + 主视觉，**≥180 字**，主视觉 ≥30% |
| 卡片组 | **每卡 ≥100 字，3 卡合计 ≥300 字** |
| 思维模型 | **4–7 维度铺齐**，≥240 字，SVG ≥50% |

## 3. 增量页型规则

- **① 封面**：主标可 4 字成语双行错位。禁单字背后填色矩形、倾斜飘带、整屏暗蒙版、英文副标。
- **② 目录**：章节 ≥4 用卡组列表型（PART 卡横排或 3×2）；章节 ≤4 且有叙事顺序用故事叙事型（左图右内容单列）。
- **③ 章节过渡**：右侧主题摄影出血或色块；副标必须中文。
- **④ 前言**：大圆角卡包 ≥220 字长文，正文无衬线。
- **⑦ 数据图表**：图例、坐标轴、单位中文；涨跌可用红 / 绿。

## 4. 增量硬闸门（叠加在通用 §6 之上）

1. 页面出现非白名单英文，尤其正文、图表、章节副标、致谢页。
2. 任意可见元素非 0° 旋转。
3. 出现印章语义、落款章、红绸铺满、整屏暗蒙版、矩形色块压图。
4. L1 配图与页面主题不符，或通用大景在章节 / 内容页凑数。
5. 目录编号载体不单一，或场景与版式不匹配。
6. 思维模型多页不同款。

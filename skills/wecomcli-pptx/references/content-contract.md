# 内容契约（所有 deck 通用）

> 只规定**页型与内容结构**。色板、字体、母版、装饰、密度以所选范例套的 `DESIGN.preset.md` 为准；两者冲突时预设赢（用户模板路径下由 `DESIGN.template.md` 取代预设，见 create-from-template.md）。
>
> 本文件对每一份从零生成的 PPT 都生效，不分场景。命中政务闸门时**再叠加** [government-contract.md](government-contract.md)，那份只写增量与更严的项。

## 1. 内容原则

- **标题是结论句**：正文页主标题必须是完整结论句（「华东区增速是全国的 2.1 倍」），不是「市场分析」这类关键词。
- **三层结构**：每个正文页至少有标题、主体（卡 / 图 / 表）、底部结论或数据锚点三层。缺一层就换版式，不用空白撑高。
- **数据可追溯**：数字、年份、排名、引语、公式、文献必须来自用户材料或 `RESEARCH.md`，并在数据页、结构图页给出 Source / Footnote。**禁止杜撰数据、虚构公式、编造文献**；确实要放示范数字时标「示例数据」。
- **结构图优先**：能用信息结构图讲清的内容不堆卡片；建议全篇 ≥20% 页面为结构图。
- **大字优先**：正文字号下限优先级高于字数下限。塞不下就精简文案或拆页，**不缩字号硬塞**。
- **视觉类型统一**：全篇 L1 主视觉是同一种类型（材料照片 / 原生图表 / SVG / 巨字），不混搭。

## 2. 页面信息下限

| 类型 | 下限 |
| :-- | :-- |
| 封面 | 主标 + 副标 + 单位或 Logo + 时间，≥20 字 |
| 目录 | 3–8 条，每条编号 + 章节名 + 摘要，≥80 字 |
| 章节扉页 | 巨字编号 + 章节标题 + 子要点，≥30 字 |
| 前言 / 执行摘要 | 单段长文 ≥220 字，或 Context / Complication / Resolution 三栏每栏 80–120 字 |
| 单主题页 | 正文 + 主视觉，≥120 字，主视觉 ≥30% |
| 卡片组 | 每卡 ≥40 字，3 卡合计 ≥120 字 |
| 思维模型 | 模型名 + 全部维度，≥160 字，SVG ≥50% |
| 数据图表 | 主图 ≥50%，洞察 50–150 字，≥1 个关键数字 |
| 表格页 | 表格 ≥70% 内容区 + 结论条 |
| 信息结构图 | 结构图 ≥70% 内容区 + Source |

正文页内容累计高度须填满内容区 ≥85%。任意页字数低于下限 70% 即返工。

**上限由容器定，优先于下限**：以上都是下限，字数上限永远是那一页容器装得下的量。`buildall` 的文字装箱机检报 `OVER` 就删字、砍掉一个块或拆页，不得为了凑下限或凑 85% 硬塞，也不得缩字号、改外壳数值或把容器改高。

## 3. 页面类型

- **① 封面**：主标、副标、单位 / Logo、时间 / 版本。禁满版照片、烟花飘带、巨字水印。
- **② 目录**：3–4 项单行 N 列；5–6 项 2×3；7+ 项 2×4。条目 = 编号 + 章节名 + 摘要；同一页编号载体只能一种。
- **③ 章节扉页**：全篇一种样式，巨字编号 + 章节标题 + 2–4 要点。
- **④ 前言 / 执行摘要**：一段 ≥220 字长文（可首字下沉 + 底部强调句），或三栏 Context / Complication / Resolution。禁把长文拆成多卡分栏凑版面。
- **⑤ 正文**：⑤a 双栏对照（两卡 + 中央连接件 + 底部结论）；⑤b 三栏并列（允许一张凸显）；⑤c 四 / 六栏小卡；⑤d 流程时间轴 4–6 步；⑤e 大图配文（主视觉 50–60%）；⑤f 数据强调（KPI / 圆环 / 三联数 + 注解 + 结论）；⑤g 对比 VS；⑤h 关键词矩阵 2×2 / 2×3；⑤i 综合复杂（≥5 类组件）。
- **⑥ 思维模型**：模型名 + 中央 SVG 结构图 + 各维度说明；全篇同款。
- **⑦ 数据图表**：白名单柱、折、瀑布、散点、树状、Mekko、2×2；**黑名单立体饼 / 立体柱、3D 散点、雷达、螺旋、彩虹色**。必备结论式标题、主图 ≥50%、洞察、Source / Footnote、单位。
- **⑧ 信息结构图**：战略房屋、2×2 矩阵、Issue Tree（从左向右）、价值链 chevron（≥85% 宽，尾节右箭头）、流程图、桥图 / 瀑布（首末全高柱、中间浮空柱涨跌两色）、Mekko、实施甘特、多支柱网格、散点 / 气泡、漏斗、组织 / 利益相关方地图。节点用矩形、圆角矩形、圆、chevron、梯形等白名单形状；直线或直角折线，**禁曲线**。
- **⑨ 结束页**：延续封面体系。

## 4. 卡片纪律

- **卡内五段骨架**：S1 标题条、S2 引导句、S3 主体正文、S4 关键数据 / 引文、S5 尾部标签。S1 / S3 / S4 必填，S4 锚底；信息太少就改版式，不用空白撑高。
- **对齐**：同组卡等宽等高，顶边对齐误差 ≤4px，gutter 误差 ≤4px，卡高差 ≤16px，卡尾元素锚底。
- **排布**：卡片数必须与列数匹配，末行不留坑；左右两栏底部高度不得悬殊。
- **焦点**：陈述型卡与焦点型卡约 3:1 或 4:1，避免全页无焦点或焦点泛滥。
- **多卡页双重锚定**：一种物理连接（连线、中央连接件、共享底条）+ 一种共享锚点（对齐线、统一色块、同位数字），否则会散成卡片堆。

## 5. 文图分离（强约束）

结构图、流程图、价值链、思维模型的**形状层**用 SVG 或原生图形；**所有文字必须是独立可编辑 Text，禁止烤进 SVG**；禁止整块含字 SVG / 位图。

## 6. 硬闸门（内容相关，命中任一即当页返工）

1. 正文页标题不是完整结论句。
2. 正文页缺三层结构，或正文卡缺 S1 / S3 / S4，或卡内出现明显空白带。
3. 数据页 / 结构图页 / 图表页缺 Source / Footnote / 关键数字。
4. 数字、公式、文献无据可查，又没标「示例数据」。
5. 文字烤进 SVG，或结构图退化为位图。
6. 结构图可用却堆卡片；⑧ 占比明显不足。
7. ⑧ 使用曲线连接或非白名单形状；图表出现 3D、雷达、螺旋、彩虹色。
8. 卡片组末行残缺留坑，同组卡不等宽等高，或多卡页缺双重锚定。
9. 正文页内容未撑满内容区（<85%），或任意页字数低于下限 70%。
10. L1 视觉类型全篇混杂。
11. 文字溢出（`buildall` 报 `OVER`）、断词异常、对比度 <4.5:1。
12. 页码 / 单位 / 顶部 chrome 全篇不一致。
13. 占位文未清零。

## 1. 气质一句话
印刷节目单式的表彰册：白纸面上一层极淡的金色圆点纸纹，细红线描边卡片配红卡头与金短条，封面朱红满版上宋体金渐变主标对着右下角一枚斜体年份巨数。

## 2. 色彩池

> **本节是默认配色，不是限制。** 模板只定版式：外壳、分区、字号层级、图位、标志性处理。颜色可以整体替换——按下表的「角色」一一对应给出新色值，用 `build_page.py init --map` 换色，再过 `contrast`。换色时保持角色数量不变（不多加一种彩色），本预设 §6 / §7 里关于「只用某种颜色」「禁止某色相」的话只约束默认配色。

## 4. 母版三区（页面 padding 50 / 64，封面与内容页相同）
- 纸纹：每页第一个子元素是整页 1280×720 的绝对定位 SVG 圆点纹（内容页 pattern id 固定写 `dots`，封面写 `dotsCover`）。
- A 标题栏：y 50–134，高 84（含 paddingBottom 14 与底部 1.5px 深朱红实线）。左红竖条 10×44 + 46px 主标，右三枚金圆点 + 15px 元信息，与主标底对齐。标题只用 46px / 700 一种字号，单行不换行，最多 16 个汉字；右侧元信息最多 20 个字。
- B 内容区：x 64 / y 152 / 1152×488；页面内容只放在这个 Box 里。六卡 2×3（372×232，gap 18）；阶段轴 = 一句引言 + SVG 轴（1152×52）+ 5 张 216×336 线框卡，gap 18，节点与卡片中线对齐；图文页为左文 437×488 + 右红线框图卡 691×488，gap 24（见「图位」）。
- C 页脚：绝对定位。y 660–669 红橙三段装饰条 678 / 333 / 269（x 0，通栏 1280）；右下 Times New Roman 斜体 15px 页码（right 64 / top 678）。
- 封面：padding 同为 50 / 64；主体是一个 1152×590 的左右两栏 Box（y 50–640，左 700 顶对齐，右 440 底对齐）；底部 y 658 金线 + y 660–720 深朱红底带（与内页装饰条同起于 y 660），页码同在 right 64 / top 678，改浅金 `#FFE79B`。

### 固定骨架

内容页外壳：
内容页外壳以本套 `shell/content.jsx` 为准（占位 `〔…〕`，B 区标记 `〔B区内容〕`），用 `scripts/build_page.py build` 拼装，不照抄手打。

封面外壳（光晕 Box 与粒子 SVG 照 `slides/01_cover.slide` 写在纸纹之后、金细线之前；这里只列与内页对齐的固定件）：

纵向算账：
- 内容页：50（padding-top）+ 84（A）+ 18（gap）+ 488（B）+ 20（gap）+ 33（C：装饰条 9 + 间隔 9 + 页码 15）+ 27（底部留白）= 720。
- 封面：50（padding-top）+ 590（两栏主体）+ 18（gap）+ 62（金线 2 + 底带 60）= 720。

所有内容页必须从此外壳复制，只替换占位文字和 B 区内部；不得改动外壳里的任何数值。B 区放不下就删内容或拆页，不得压缩页眉页脚或改 padding。封面同理：只替换占位文字和左右两栏的内部，左栏内容总高不得超过 590。

**封面标题容量（硬上限）**：124px 金渐变标题，左栏 700 宽：最多 2 行（短标题只写一行，不得为凑两行硬拆；空出的那一行保留原有占位高度，其余元素位置不变），每行一个 Text（各占 148 高），每行最多 5 个汉字；更长的名称放进下方的飘带 / 胶囊行，不得加第三行。标题与页脚、底带之间必须留出空隙，任何情况下标题不得压到页脚上。

**装饰与文字不重叠（硬约束）**：封面右下斜体年份巨数占右栏，左栏文字宽 700、总高不超过 590；底部三段装饰条 y 660～669 之上 20px 内不放文字。装饰性 SVG / Box 的矩形与任何文字容器的矩形不得相交；页型没有范例时，装饰只照本套封面或内容页范例的位置放，不另加。

### 图位（配图规则）
- 图位（唯一，正方形）：x 776 / y 152 / 440×440，右，下方 48 高图注行；左侧 688 宽文字列。范例见 `slides/04_image.slide`；封面、章节页及其他内容页不放图。
- 没有生图工具，不放 AI 配图；图位只放合格的用户材料图（门槛见 README §5）。`<Image>` 只写相等的 width / height，不写 objectFit；图不加描边、相框、包边线、圆角、阴影；图注一行放图下方。原因与材料图写法见 README §5。
- 有合格材料图时图文页最多 2～4 张、不连续；没有就不用图文页，改用本套其他版式，不留空图位。

## 6. 标志性处理
1. 细线描边卡片：卡、方角标签为 1.5px 线框、0 圆角；胶囊 999 圆角；徽章与节点为正圆。线框色由锈红单色改为深朱红。
2. 每页整页 6px 圆点纸纹 SVG pattern：内页金点 `#FBF1E0`（`#E19825` 按 14% 预混到白底）、封面浅金点 `#EA5A39`（`#FFE79B` 按 16% 预混到朱红底）；纸纹 SVG 第一个子元素是整页实底 rect（页底色），不在 svg 的 style 上写 opacity。
3. 封面右下斜体年份巨数保留为版面锚点，改深朱红同色系压在朱红底上；左侧主标改宋体金渐变并加光晕。
4. 引入的红金要素：金渐变大字、径向光晕、金色水平飘带、金边红胶囊、金色粒子与细金线、红卡头、卡内金短条、红圆金描边节点、底部三段装饰条加页码、标题红短竖条。
5. 卡内节奏：红卡头或阶段名在上，金短条承接，底部 1px 红虚线分隔卡尾。
6. 页码只在右下（right 64 / top 678），Times New Roman 斜体，封面与内页同坐标。

## 7. Do / Don't
Do
- 标题栏下 1.5px 红线贯通全宽，右侧元信息与主标底对齐。
- 六卡等尺寸等 gap，主体 STSong 700，说明 ≤2 行；数量数字用 Times New Roman bold 深朱红。
- 阶段轴线与节点全部 SVG 且不与卡片重叠，中文一律用 Text；节点数字可留在 SVG 内。
- 封面主标每行单独一个 Text，外包 Box 高度取字号 ×1.2；光晕 Box 用正方形。
- 配图只用 `<Image>` 放进 §4「图位」表里的固定图位，外包细红线框图卡，图注放在图下方的图注行。
- 状态词只用「已完成 / 进行中 / 待举行 / 评审通过 / 公示通过」等中性表达。
Don't
- 不给卡片加圆角、阴影；线框不超过 1.5px；内页不铺红底。
- 不把金用于正文文字或大面积色块；金渐变大字只在封面出现。
- 不把中文写进 SVG，不用斜体中文。
- 不在封面放图；不在图上叠文字、色块或渐变；不给图加圆角、阴影；不用卡通、插画、3D 配图。
- 不旋转任何元素，不放印章、红绸、整屏暗蒙版；页面英文为零（仅阿拉伯数字）。
- 不用清单外字体；含中文的 Text 必须写 STSong。

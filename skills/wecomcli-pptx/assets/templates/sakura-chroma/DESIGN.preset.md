## 1. 气质一句话
一张日本复古磁带的包装纸：奶油纸底上五条斜彩带一掠而过，深棕粗黑大字压在黄色标签块里，四栏产品卡各顶一条彩色细条，角落有等宽小字和方框勾选项，像一份印在硬纸上的产品目录。

## 2. 色彩池

> **本节是默认配色，不是限制。** 模板只定版式：外壳、分区、字号层级、图位、标志性处理。颜色可以整体替换——按下表的「角色」一一对应给出新色值，用 `build_page.py init --map` 换色，再过 `contrast`。换色时保持角色数量不变，本预设 §6 / §7 里关于「五色彩带」「只用深棕」的话只约束默认配色；本套是**多色套**，`palette` 时 `--spread` 留在 0.6 以上才能保住五条彩带的色相距离。

| 角色 | hex | 用途 | 面积占比上限 |
|---|---|---|---|
| 纸底 paper | `#F3E9D2` | 全页底色；引言框与勾选框的填色 | 整版 |
| 卡面 surface | `#EBE0C6` | 产品卡、表格斑马行 | ≤45% |
| 墨 ink | `#3B2A1B` | 全部标题、正文、线、表头底、硬阴影、徽章、署名底 | 文字与 ≤15% 的面 |
| 次级文字 muted | `#6B5A44` | 页脚、卡内注释、规格键名（纸上 5.1:1，卡面上 4.7:1） | 文字专用 |
| 线 line | `#C9BBA0` | 卡内 1px 分隔线、表格行线 | 线 |
| 红 red | `#E24B3B` | 彩带 / 卡顶条 / 徽标圆 / 小胶囊底（胶囊上用纸色字，5.0:1） | 装饰 |
| 粉 pink | `#E5408C` | 彩带 / 卡顶条 / 徽标圆 | 装饰，**不承字** |
| 橙 orange | `#F08A3C` | 彩带 / 卡顶条 / 徽标圆 / 表格状态格（墨字 5.0:1） | 装饰、状态格 |
| 黄 yellow | `#F2C232` | 彩带 / 封面标题块底 / 表格状态格（墨字 7.9:1） | ≤12% |
| 绿 green | `#3FA34B` | 彩带 / 卡顶条 / 徽标圆 / 表格状态格（墨字 4.6:1） | 装饰、状态格 |

对比度纪律：墨在纸、卡面、黄、橙、绿上都 ≥ 4.6:1；**粉与蓝只做装饰，不放任何文字**；红上只放 ≤ 11px 的纸色胶囊字。

## 4. 母版三区

- 所有内容页 Slide style 逐字相同：`width: 1280, height: 720, background: '#F3E9D2', padding: '32px 40px 24px 40px', position: 'relative', flexDirection: 'column', fontFamily: 'Microsoft YaHei'`。版心 1200 宽（x 40–1240）。
- A 标题带（y 32–120，高 88）：一行 48px 结论句（宽 860）左、Courier 12 大写 kicker 右，两者 `alignItems: 'flex-end'` 贴着底部的 2px 墨线（`borderBottom`，`paddingBottom: 12`）。
- B 内容区（y 140–652，宽 1200、高 512）：页面内容只能放在这个 Box 里。
- C 页脚（y 664–696，高 32）：左 11px 中文页脚标签（muted），右 Courier 12 `NN / 总页`（墨）。**页脚不做块**，是纸面本身。封面与引言页也用同一 C 区（absolute `top: 664`），坐标一致。

### 固定骨架

纵向算账：32（padding-top）+ 88（A）+ 20 + 512（B）+ 12 + 32（C）+ 24（padding-bottom）= 720。
横向算账：40 + 1200 + 40 = 1280；四栏卡 1200 = 4 × 282 + 3 × 24。

内容页外壳以本套 `shell/content.jsx` 为准（占位 `〔…〕`，B 区标记 `〔B区内容〕`），用 `scripts/build_page.py build` 拼装，不照抄手打。

封面与引言页是自定义版式（见 §5）：同一 Slide style，元素用 absolute 定坐标，C 区与内容页逐字相同。

| 区 | x | y | w | h |
|---|---|---|---|---|
| A 标题带（含底线） | 40 | 32 | 1200 | 88 |
| A 内标题 Text | 40 | 贴底线向上 | 860 | ≤ 66 |
| B 内容区 | 40 | 140 | 1200 | 512 |
| 四栏卡 | 40 起，步进 306 | 140 | 282 | 512（顶条 8 + 卡体 504） |
| C 左标签 / 右页码 | 40 / 右缘 1240 | 664 | 自适应 | 32 |
| 封面彩带 SVG | 560 | 56 | 520 | 400 |
| 封面巨型编号 | 40 | 约 170 | 自适应 | 160 |
| 封面勾选项列 | 1100 | 250 | 140 | 约 130 |
| 封面标题块行 | 40 | 500 | 1200 | 约 130 |
| 引言页彩带 SVG | 0 | 0 | 1280 | 720（穿全页） |
| 引言框（含 6px 硬阴影） | 40 | 300 | 906 | 170 |

所有内容页必须从此外壳复制，只替换占位文字和 B 区内部；不得改动外壳里的任何数值。B 区放不下就删内容或拆页，不得压缩标题带或改 padding。

**标题容量（硬上限）**：A 区标题 48px / 行高 1.15、宽 860，**只允许 1 行，最多 17 个汉字**；写不下就改写，不得换行、不得缩字号。封面标题块 52px 一行 ≤ 12 个汉字；引言框 40px / 行高 1.2、宽 840，最多 2 行、每行 ≤ 21 个汉字。卡片标题 22px 最多 2 行（≤ 20 字），卡内正文 14px 最多 5 行（≤ 85 字），注释最多 2 行（≤ 34 字）。

**装饰与文字不重叠（硬约束）**：封面彩带占 x 560–1080 / y 56–456，封面上的文字只在它左边（x ≤ 520）、右边（x ≥ 1100）和下边（y ≥ 500）；**引言页是本套唯一允许彩带穿过文字容器背后的页**——引言框是纸色实底 + 2px 墨边 + 6px 墨色硬阴影的封闭容器，文字永远落在纸色上，彩带只在框外可见；除引言框外，任何文字容器的矩形不得与彩带、圆环、色块相交。徽章圆（52×52 墨色圆 Box）是本套**唯一的圆角元素**，其余 Box 一律直角。

### 图位（配图规则）
- 本套不放 AI 生成的配图（当前环境没有生图工具）：封面、引言页、内容页都以 §6 的标志性处理作主视觉。
- 只有用户提供的材料图可以上页，作为证据图，每页最多一张。图位是 B 区里替换掉左侧两栏卡的正方形块：x 40 / y 140 / 512×512（右侧 664 宽放两张卡或说明）；按真实比例居中放置（`<Image>` 宽高 = 图位边长按真实宽高比缩放），不写 objectFit，不加描边、相框、圆角、阴影，图注一行放图下方的 C 区左侧。
- 材料图上页的门槛：只有照片、真实海报、界面截图这类重画不出来的内容才放，且原图短边 ≥ 512。材料里的表格、流程图、排期表一律不贴图，改用原生 `<Table>`、Box 排版或 SVG 重画；重画不了又不清晰的，宁可不放。
- 图位宽高不得改；没有材料图就不留图位，不得用彩色块或卡片冒充图片——彩带与色块是版式语言，不是图片替身。

## 6. 标志性处理

1. **斜彩带**：五条等宽平行四边形（粉 / 橙 / 黄 / 绿 / 蓝，顺序固定），条间留 6px 纸底缝，用 `<path>` 的斜边实现倾斜，**不用 rotate**。封面右上一组（向右下降），引言页全页一组（向右上扬），一页只出现一组。
2. **标题住在色块里**：封面主标压在黄色块上，色块只包住文字（`flexDirection: 'row'` 让它收缩），块下压一条 2px 墨线。
3. **彩色顶条**：卡片顶部 8px 实色条是卡片的唯一装饰，四张卡四种色，顺序红 / 粉 / 橙 / 蓝；卡体直角、无边框、无阴影。
4. **硬阴影**：引言框用一个偏移 6px 的墨色 Box 垫在下面充当阴影——没有 boxShadow，没有模糊，就是一块实色。全套只有引言框用它。
5. **等宽小字**：kicker、卡片编号、页码、胶囊一律 Courier New 全大写加字距；勾选项用「■ / □」做前缀，是本套的产品目录腔调。
6. **五圆徽标**：五个彩色圆两两相叠，只出现在封面左上，颜色顺序蓝 / 红 / 绿 / 橙 / 黄。

## 7. Do / Don't

Do：
- 每页至少一处彩色（顶条、彩带、状态格或徽标），但文字永远只用墨与 muted 两色。
- 结论句写成完整的话（「四场活动，一周排完」），不写「活动一览」这种词组。
- 卡内用 `justifyContent: 'space-between'` 让规格块钉底；规格键值一行一对，键左值右。
- 表格状态列用整格填色表达状态，只用黄 / 橙 / 绿三色承墨字。

Don't：
- 不给卡片、色块、标题块加圆角或阴影（徽章圆例外）；不用 boxShadow、渐变、模糊。
- 不把文字放在粉、蓝彩带或色块上；不在红上放 12px 以上的字。
- 不用 Courier New 写中文，不用它写 ≥ 30px 的数字。
- 不让彩带穿过引言框以外的任何文字容器；不用 rotate 做倾斜。
- 不出现 emoji；不写注释；A 区标题只有一行。

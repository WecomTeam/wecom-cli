## 1. 气质一句话
像一本时尚杂志的封面或十九世纪的剧院海报：粗黑巨字居中排布、只有大数字与西文编号留衬线，双线饰条把居中的字括起来，企业微信品牌蓝与白两色，直角、无阴影、无渐变，全靠白面板、浅蓝色块和 3px 线做层次。

## 2. 色彩池

> **本节是默认配色，不是限制。** 模板只定版式：外壳、分区、字号层级、图位、标志性处理。颜色可以整体替换——按下表的「角色」一一对应给出新色值，用 `build_page.py init --map` 换色，再过 `contrast`。换色时保持角色数量不变（不多加一种彩色），本预设 §6 / §7 里关于「只用蓝白」「禁止第二种彩色」的话只约束默认配色。

| 角色 | hex | 用途 | 面积上限 |
|---|---|---|---|
| 品牌蓝 accent_blue | `#267EF0` | 全套的色相基准；白面板上的 3px 线、图表主系列等非文字元素 | 非文字元素不限 |
| 承字蓝 darken_1 | `#2373DA` | 整版底色、白 tile 内的大数字与 delta pill 底、白面板上的巨型编号；与白互为文字 / 背景时对比 4.63:1 | 整版 100% |
| 白 | `#FFFFFF` | 蓝底上的全部文字与 3px 线；章节页半幅面板；KPI tile 底；蓝底上的 pill 底 | 内容页 ≤ 50%，章节页 50% |
| 深蓝 darken_5 | `#1A4785` | 白面板 / 浅蓝 tile 上的标签、大数字、说明、pill 底（对白 9.2:1，对浅蓝 7.6:1） | 只做文字与 pill |
| 浅蓝 lighten_5 | `#DCEBFD` | 交替 tile 的底色，图表次系列 | ≤ 30%，只在 tile 轮换里出现 |
| 中性：近黑 `#10141A`（白 tile 内说明文字）、灰 `#6D7176`（只可用在白底上，4.9:1）、`#E7E7E8`（白面板内的分隔）。禁止蓝以外的任何彩色。 |
对比度纪律：`#267EF0` 与白互为文字 / 背景只有 3.94:1，因此凡是承载文字的蓝面一律用 `#2373DA`，凡是白底上的蓝字一律用 `#2373DA` 或 `#1A4785`；`#6D7176` 不放在浅蓝 tile 上（4.0:1）。

## 4. 母版三区
- 页面 padding：默认 `44px 73px 44px`（原 110/110/70 → 73/73/47 微调）；封面 `40px 73px`；章节页 padding 0，左右两个 640×720 面板各自内 padding `52～60px 60px 56px`。
- A 标题块：y 44～68 masthead（两端 16px 标签）；y 92～326 标题块（eyebrow + 两行 76px 标题，右侧可放 400px 宽说明段底对齐）。
- B 内容区：y 350～676，宽 1134（KPI tile 行高 326；图表卡 / 步骤 tile 同区）。
- C 页脚条：封面与收尾页在 y 656～680 放 footline；内容页不放 footline，用顶部 masthead 承担页码。
- 标题与页码位置全篇固定：masthead 左 73、右 73；标题块左 73。

### 固定骨架

纵向算账：44（padding-top）+ 24（masthead）+ 24（gap）+ 234（标题块）+ 24（gap）+ 326（B 区 tile 行）+ 44（padding-bottom）= 720。
横向算账：73 + 1134 + 73 = 1280；B 区 1134 = 4 × 270 + 3 × 18（KPI 行），或 3 × 366 + 2 × 18（三栏行）。

内容页外壳以本套 `shell/content.jsx` 为准（占位 `〔…〕`，B 区标记 `〔B区内容〕`），用 `scripts/build_page.py build` 拼装，不照抄手打。Slide style 逐字为 `width: 1280, height: 720, background: '#2373DA', padding: '44px 73px 44px', flexDirection: 'column', gap: 24, fontFamily: 'Microsoft YaHei'`。

封面与章节页有各自的整版版式（见 §5），不套用本外壳；但它们的 masthead / footline 左右边距同为 73，与内容页对齐。

| 区 | x | y | w | h |
|---|---|---|---|---|
| masthead 行 | 73 | 44 | 1134 | 24 |
| 标题块（eyebrow + 标题 + 右侧导语） | 73 | 92 | 1134 | 234 |
| B 区 tile 行 | 73 | 350 | 1134 | 326 |
| KPI tile（4 张） | 73 起，步进 288 | 350 | 270 | 326 |
| 三栏 tile（3 张） | 73 起，步进 384 | 350 | 366 | 326 |

所有内容页必须从此外壳复制，只替换占位文字和 B 区内部；不得改动外壳里的任何数值。B 区放不下就删内容或拆页，不得压缩 masthead / 标题块或改 padding。

**标题容量（硬上限）**：标题块里的 76px 标题行高 1.1，**最多 2 行**，换行只写 `<br />`（字符串里直接回车会被折成空格，编译器按一行量高度，标题下溢 76px 被 tile 盖住）；`STSong` 900 在 76px 下每行最多 11 个汉字（右侧 400px 导语占位，标题右边界不得越过 x 734）。eyebrow 一行、≤ 14 个汉字。右侧导语 18px / 行高 1.6、宽 400，最多 4 行（≤ 88 字）。超了改写文案，不得加行、不得缩字号。
**封面大字容量**：116px `STSong` 900 居中舞台，双线饰条上下各一行，**每行最多 6 个汉字**，只有两行，不得加第三行。

**装饰与文字不重叠（硬约束）**：双线饰条是封面与 statement 页的专属件，左右两条 3px 线靠 `flex: 1` 撑满，中间连接词占 45px，整条独占一行，上下与大字各留 ≥ 24px，不得与任何文字容器相交。章节页 300px 巨型编号必须落在左半幅白面板内，四角标签距面板边 16px；巨型编号与右半幅文字分处两个面板，不会相交。装饰性 Box 与任何文字容器的矩形不得相交；页型没有对应样例时，装饰只照本套内容页的位置放，不另加。

### 图位（配图规则）
- 本套不放 AI 生成的配图（当前环境没有生图工具）：封面、章节页、内容页都以 §6 的标志性处理作主视觉。
- 只有用户提供的材料图可以上页，作为证据图，每页最多一张。图位是 B 区 tile 行里替换掉相邻两张 KPI tile 的一个正方形块：x 73 / y 350 / 326×326（右侧 790 宽继续放 tile 或说明）；按真实比例居中放置（`<Image>` 宽高 = 图位边长按真实宽高比缩放），不写 objectFit，不加描边、相框、圆角、阴影，图注一行放图下方的 tile 内。
- 材料图上页的门槛：只有照片、真实图表、界面截图这类重画不出来的内容才放，且原图短边 ≥ 326。材料里的表格、流程图、对比图、文字截图一律不贴图，改用原生 `<Table>`、`<Chart>`、Box 排版或 SVG 重画；重画不了又不清晰的，宁可不放。
- 图位宽高不得改；没有材料图就不留图位，不得用白面板或浅蓝 tile 冒充图片——本套的白块是版式语言，不是图片替身。

## 6. 标志性处理
1. 双线饰条：居中词两侧各两条 3px 线（间距 2px），必须左右对称；蓝底上用白线，白面板上用 `#267EF0` 线；用于封面「X 之 Y」和 statement 页的连接词。
2. 粗黑巨字：`Microsoft YaHei` 700、行高 1.0～1.1、封面 116px；衬线只在大数字与 300px 西文编号上出现，巨型编号只放在白面板上，用 `#2373DA`。
3. 白面板 / tile：蓝底上的白块是「抬升」语言，浅蓝 `#DCEBFD` tile 交替打破单调，全部直角。
4. 3px 线：所有分隔（段落之间、tile 内、列表行）都是同一根线，绝不用 1px。
5. masthead / footline：封面与收尾页顶底各一行两端对齐的 700 字重白色标签。
6. 方角 pill：标记 / 标签 / delta 都是无圆角小色块；蓝底上为白底深蓝字，白 tile 内为 `#2373DA` 底白字，浅蓝 tile 内为 `#1A4785` 底白字。

## 7. Do / Don't
Do
- 显示标题一律 `Microsoft YaHei` 字重 700，中文字距 0、行高 1.0～1.1；KPI 大数字用 `STSong` 900，纯西文与数字的巨型编号用 `Times New Roman`。
- 标签、eyebrow、pill、footline 一律 `Microsoft YaHei` 700 + 3～5px 字距；30px 以下的西文 / 数字标签用 `Courier New` span 全大写。
- 所有 Box 不写 `borderRadius`；分隔线用 `<Box style={{ height: 3, background: '#FFFFFF' }} />`（白面板上换 `#267EF0`）。
- 蓝面上的文字只用 `#FFFFFF`；白面板上标题与数字用 `#2373DA` 或 `#1A4785`，正文用 `#10141A` / `#6D7176`；浅蓝 tile 上的文字只用 `#1A4785`。
- 承载文字的蓝面写 `#2373DA`，不承载文字的蓝色元素（线、图表系列、色条）写 `#267EF0`。
- 一页一个巨型标题 + 3～4 个支撑元素；tile 内尾部说明用 `justifyContent: 'space-between'` 钉底。
- 图表用原生 `Chart`，装进白卡，`colors={['#267EF0', '#ACCFFA']}`、`background='#FFFFFF'`。
Don't
- 不加 `boxShadow`、`textShadow`、渐变、模糊。
- 不用圆角，不用 1～2px 结构线（2px 只给图表网格线）。
- 不把 300px 巨型编号直接放在蓝底上，必须有白面板托底。
- 不在蓝底上放浅蓝或灰色小字（`#DCEBFD` 对蓝 3.8:1、灰更低），不在白底上放 `#65A4F5` 及更浅的蓝字。
- 不出现蓝以外的彩色；浅蓝只做 tile 轮换，不做整版底。
- 不引入第四种字体，不用斜体、下划线；标题字重 700。
- 不在一页里堆六个以上小元素；不做正文居中（只有封面舞台居中）。

## 8. 移植取舍
- grid：KPI 四栏、章节页两栏都改为 row + 固定 px（270×4 + 18×3 = 1134；640 + 640）。
- 双线饰条：原 CSS 伪元素改为两组嵌套 Box，各含两条 3px 高 Box，`flex: 1` 撑满两侧。
- 字体：原模板高反差衬线 display → 中文标题 `Microsoft YaHei`（700，2026-09-22 起）、KPI 大数字 `STSong`（900）、西文与数字 `Times New Roman`；原模板无衬线正文 → `Microsoft YaHei`（700 / 400）；`Courier New` 只承担 30px 以下的西文数字标签；大写转换改为直接书写大写。
- 配色：原模板的绿、深藏青、米纸三色整体换为品牌蓝、白、浅蓝；深色面板的角色交给白面板，文字色按所在底色逐个重定而非互换。
- 巨型编号 460px → 300px，仅当内容为纯西文时用 `Times New Roman`，中文编号改用 `STSong` 并进一步降至 240px 左右。
- 绝对定位 masthead / footline 改为 Slide 主轴 `space-between` 的首末子项；单线 / 无线饰条变体、动画与舞台缩放放弃。
